КОМПЛЕКТ «ЛИТЕРАТУРА · 5–9 КЛАССЫ»

В архиве отдельная HTML-страница для каждого пункта списка.
Откройте index.html в браузере и выберите класс или воспользуйтесь поиском.

Структура:
- index.html — общий каталог;
- grade-5/ ... grade-9/ — отдельные страницы произведений;
- в каждой странице есть литературный паспорт, содержание/характеристика, герои, темы, вопросы для анализа и интерактивный тест.

В карточках для 16 произведений 5-го класса добавлен развёрнутый материал из файла «5_klass (1).docx».
Повторяющиеся произведения оставлены в соответствующих классах отдельными файлами.
Обзорные пункты «лирика», «оды», «сонеты» и выборочные фрагменты отмечены как обзоры: конкретный список текстов зависит от учебника.

Все страницы автономны и открываются локально; интернет для просмотра не требуется.
